Worklet addModule() Errors

This playground intentionally triggers exceptions using AudioWorklet.addModule() to demonstrate how different failures (like 404s, CORS, or Invalid States) manifest in the browser.

1. HTTP 404 (Not Found)

Attempts to load a module from an endpoint that returns a 404 status code.

AudioWorklet

2. JS Syntax Error

Loads a module via Blob URL that contains intentionally invalid JavaScript syntax.

AudioWorklet

3. Blob URL + Query Param

Attempts to load a Blob URL that has a query string appended, which causes fetch failures in some browsers.

AudioWorklet

4. CORS / Network Fail

Attempts to load a script from a cross-origin URL (example.com) that does not provide correct CORS headers.

AudioWorklet

5. Close During addModule

Calls addModule() without awaiting, immediately closes the context, and then checks the module promise.

AudioWorklet
