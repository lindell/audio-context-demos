AudioWorklet Subnormal Test

This demo tests the performance impact of processing subnormal (denormal) floating-point numbers within an AudioWorklet. Subnormal numbers are very close to zero and historically cause severe performance degradation on many CPU architectures. While we cannot explicitly force execution onto E-cores (Efficiency cores) via Web APIs, running a heavy, continuous workload might influence the OS scheduler.
